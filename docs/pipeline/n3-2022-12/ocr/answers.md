## Transcription conventions

- Each mapping is written as `question number → answer value`.
- The answer value is the value in the row labeled `答案` / `Answer`; it is not a question number.
- `問題` labels are preserved. In **Choukai**, question numbers restart at 1 for each `問題`, so the mappings are scoped by `問題` and must not be merged across tables.
- No visible cells were judged uncertain. The section titles use the characters as visibly transcribed; where the scan uses Chinese variants (`词汇`, `读解`, `听解`), those are retained in the source-label notes.
